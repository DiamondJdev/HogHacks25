# HogHacks25

## 🏆 Winner of Best Implementation @ 2025 HogHacks Hackathon (University of Arkansas)

Chakra Clash is an innovative hackathon project built in just 24 hours at the University of Arkansas's 2025 HogHacks event. 
Competing against top college teams, Chakra Clash earned 4th place and the **Best Implementation** award for its creative use of technology and seamless integration.

## 🚀 What is Chakra Clash?

Chakra Clash is a real-time competitive Yoga ranking app designed to make group Yoga sessions more fun—and a little mischievous. 
Participants are ranked on their pose accuracy using machine vision, while the app sends cheeky and impudent messages to keep everyone on their toes.

### Features

- **Deno Backend**  
  High-performance, modern backend built with [Deno](https://deno.com/), powering real-time scoring and impudent messaging.

- **Flutter Frontend**  
  Sleek and responsive UI made with [Flutter](https://flutter.dev/), providing a seamless experience across devices.

- **Novel Machine Vision Model**  
  Custom-trained ML model capable of detecting and evaluating Yoga poses through live video feeds.

- **Competitive Ranking System**  
  Score and rank players live. See who's top yogi—and who's getting roasted!

- **Impudent Messaging**  
  The app throws playful, distracting comments at contestants, making the competition both hilarious and challenging.

## 🚦 How it Works

1. **Players join a Yoga session via mobile/web app.**
2. **Pose detection runs in real-time, scoring accuracy using the ML model.**
3. **Leaderboard updates as players strike new poses.**
4. **Random impudent messages pop up to throw off focus and keep things lively!**

## 🛠️ Tech Stack

- **Backend:** Deno
- **Frontend:** Flutter
- **ML Model:** Custom yoga pose detector
- **Other:** WebSockets, REST API, real-time video analysis

## 🤖 Machine Vision Model

- Trained specifically for Yoga pose detection
- Fast, accurate, and works with regular webcams
